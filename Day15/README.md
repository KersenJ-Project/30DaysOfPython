# Jour 15 — Types d'erreurs Python

Ce dossier contient un fichier Python par type d'erreur étudié :

1. `SyntaxError`
2. `NameError`
3. `IndexError`
4. `ModuleNotFoundError`
5. `AttributeError`
6. `KeyError`
7. `TypeError`
8. `ImportError`
9. `ValueError`
10. `ZeroDivisionError`

## Utilisation

Ouvre un terminal dans ce dossier et exécute un fichier, par exemple :

```bash
python 01_syntax_error.py
```

Les exemples qui provoqueraient une erreur sont commentés (`#`) pour que chaque fichier puisse être exécuté et affiche la correction. Pour observer l'erreur originale, enlève le `#` devant l'exemple fautif et commente la correction.

Remarque : `SyntaxError` empêche Python d'analyser le fichier, donc son exemple doit rester commenté si tu veux exécuter la correction dans le même fichier.
